# SX Gestão

MVP Android offline: Kotlin, Compose, Room, MVVM simplificado, um módulo `:app`
e mínimo Android 7/API 24. Dinheiro usa centavos com `Long`.

- [Checklist e evidências](docs/implementation-checklist.md)
- [Validação no Android Studio](docs/manual-validation.md)
- [Requisitos](docs/srs.md) e [regras financeiras](docs/business-rules.md)
- [Arquitetura](docs/architecture.md) e [banco](docs/database-design.md)
- [Formato de backup](docs/backup-format.md)

Abra esta pasta no Android Studio, sincronize e execute `app` em API 24 ou
superior. Backup/restauração ficam em Configurações e usam o seletor Android.
Não há servidor, login ou permissão de internet.
